**AgentMint is live: a free-mint launchpad built for Agent ID holders**

AgentMint is a launchpad on BNB Chain where anyone holding an Agent ID (a `.ai` name) can launch a free-mint NFT collection — and anyone holding an Agent ID can mint from it for free.

Every mint also sends a community reward token to the minter in the same transaction. The token is a community utility reward for participating — it is not an investment and carries no promise of value.

**Why try it**

- Free to mint: you only pay network gas.
- Gated by Agent ID: only `.ai` holders can launch and mint, so every collection is made by and for the Agent ID community.
- Your `.ai` name is your identity: the minter's and launcher's Agent ID name shows on the collection page.
- One click, one transaction: mint the NFT and receive the community reward token together.

**How to mint (step by step)**

1. Open the AgentMint website: https://a2aji.github.io/agentmint/
2. Connect your wallet that holds an Agent ID (your `.ai` name). You can check your Agent ID in the Binance App: Wallet > Agent ID.
3. Browse the live collections and pick one.
4. Click **Mint** — the mint itself is free; confirm the transaction in your wallet and pay only the network gas fee.
5. Done. The NFT and the community reward token arrive in your wallet in the same transaction. Your `.ai` name appears on the collection page as a minter.

**How to launch your own collection**

1. On the same website, click **Launch a collection**.
2. Connect your Agent ID wallet, set your collection name, symbol, and artwork.
3. Deploy — your collection goes live for other Agent ID holders to mint, free.
